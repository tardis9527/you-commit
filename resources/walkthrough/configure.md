# 配置 AI 模型

YouCommit 提供两种使用方式：

---

## ⚡ 内置服务（推荐新手）

无需任何 API Key，购买密钥即可使用，开箱即用。

1. 点击下方「立即配置」，选择 **⚡ 内置服务**
2. 点击「购买额度」获取密钥，或直接输入已有密钥
3. 密钥激活后即可使用，状态栏显示剩余次数

---

## 🔑 自带 API Key（BYOK）

支持任何兼容 OpenAI API 格式的平台：

- **OpenAI** — `https://api.openai.com/v1`
- **DeepSeek** — `https://api.deepseek.com/v1`
- **通义千问** — `https://dashscope.aliyuncs.com/compatible-mode/v1`
- **自定义** — 输入任意兼容 API 地址

1. 点击下方「立即配置」，选择 AI 平台
2. 输入 API Key
3. 选择模型
4. 自动验证连接

---

两种模式可随时在设置中通过 `youcommit.serviceMode` 切换。
