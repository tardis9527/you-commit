# Review 2 - ⭐⭐⭐⭐⭐

作为一个对 commit 规范有强迫症的开发者，这个插件简直是救星。以前每次提交都要纠结怎么写 message，现在一键生成，格式完美，内容精准，完全符合 Conventional Commits 规范。

几个亮点体验：
- 对中文开发者特别友好，界面和生成内容都支持中文
- 支持多种提交格式切换，conventional / gitmoji / 简洁模式随心选
- SCM 面板直接集成了生成按钮，工作流非常顺滑，不需要离开当前页面
- 即使是大量文件变更，分析速度也很快，不会卡顿

唯一的小建议是希望未来能支持自定义 prompt 模板，这样可以更贴合团队的提交规范。总体来说是目前用过最好的 AI commit 工具，五星好评！
