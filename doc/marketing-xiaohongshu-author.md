## 标题

受不了手写 Git commit 我做了个 VSCode 插件🍊

---

## 正文（直接复制发布，约 950 字）

先说为什么做这个👇

每次 git commit 我就犯病
改一行打个 "fix style" 改十个文件对着输入框发呆
有次赶 ddl 连提八个 "update" 第二天看 git log 想打自己😂

后来盯着 diff 突然想 改了啥里面写得明明白白
让 AI 帮我总结不就完了？？
说干就干 撸了个 VSCode 插件「YouCommit - 柚提」🍊

🔥 用法很简单：
暂存代码 → 点 ✨ 按钮 → AI 读 diff → 3 秒生成规范 commit message
流式输出逐字蹦出来 像雇了个小助手帮我写提交信息😎

🧐 设计上几个重点：

1⃣ 不绑死平台
BYOK 模式自带 key 接 DeepSeek/通义千问/OpenAI 都行 免费
不想折腾？内置服务买密钥直接用 后端我来维护⚡

2⃣ 5 种格式
conventional/gitmoji/简洁/详细/自定义 prompt
还能写自己的模板 完全控制生成逻辑

3⃣ 中英双语一键切 个人项目中文 公司项目英文

4⃣ 自动 commit + push 一键到底
开了之后省出来的时间够多摸会鱼🐟

5⃣ 密钥走 SecretStorage 加密 不写配置文件 安全放心

💰 比 Copilot 香在哪？
Copilot $10/月起 模型不能选 格式固定
柚提自带 key 免费 内置按次付费 还有自定义 prompt + 自动 push

VSCode 扩展商店搜「YouCommit」就能装
用了一周回不去了 再手写跟用记事本写代码一样难受😂
试试柚提🍊 问题评论区找我 作者在线！
