## 正文（直接复制发布）

不是 我真的没法再手写 git commit message 了😭

之前每次提交代码都要想半天写什么
小改动："改了个 bug"
大改动：组织半天语言 写完自己都觉得丑
更别提还要守 Conventional Commits 规范 太折磨了

直到我装了这个👇
「YouCommit - 柚提」🍊

就一个 VS Code 插件 装完改变了我的 git 人生（不夸张

✅ 怎么用？
暂存代码 → 点一下 ✨ 按钮 → AI 自动读你的 diff → 3 秒生成规范 commit message
而且是流式输出 文字一个个蹦出来 看着巨爽🤩

✅ 两种模式
⚡ 内置服务：不折腾 买个密钥直接用 小白友好
🔑 自带 Key：接 DeepSeek / 通义千问 / OpenAI 都行 0 成本

✅ 格式随便选
conventional / gitmoji / 简洁 / 详细 / 自定义 prompt
中英双语一键切

✅ 最爽的是
生成完还能自动 commit + push 一条龙
再也不用手动操作了 解放双手�

💰 比 Copilot 香在哪？
copilot 要 $10/月起步 模型还不能选
柚提自带 key 直接免费 内置服务按次付 越买越便宜
关键是 5 种格式 + 自定义 prompt copilot 给不了

📦 装法
VS Code 扩展商店搜「YouCommit」就行
装完自动弹引导 跟着点就能用 超简单

用了一周回不去了 再也没写过 "fix bug" 这种丢人 commit 哈哈哈
程序员朋友们冲🍊
